# MATRIX — AI Operations Map

A live, cybernetic, interactive operations map built specifically for **Acer-AI-Server** (Acer Aspire V3-772G running Linux Mint 22.3).

Visually maps every discoverable agent, background coordinator, model provider, tool integration, persistent memory store, and application pipeline from empirical evidence collected across the filesystem, process table, and systemd services.

---

## Features

- **Live Discovered Topology:** Real-time empirical discovery of Antigravity IDE & Daemon, Hermes Gateway (PID 1476), Codex Worker runner, Ollama local host (10 models), Phi-4 mini local route, Gemini API, GitHub MCP, and Google Drive sync.
- **Slick 3D Physical Element Design:**
  - Extruded 3D foundation slabs (`.node-3d-slab`) with physical drop shadows.
  - Elevated milled alloy & dark glass faceplates (`.node-3d-face`).
  - Directional top-rim specular highlights (`.node-3d-rim`).
  - Tactile 3D push jewel buttons (`[ℹ]`) with enlarged hit targets.
- **Plain-English Non-Technical Guide:** Clicking `[ℹ]` on any component displays a non-jargon explanation of what it is, why it matters, current real-life status, and how to use it.
- **Fluid Dynamic Conduits & Bubbles:**
  - Quadratic Bézier conduit pipes with outer protective glass jackets.
  - Continuous lightweight 60 FPS flowing liquid bubble simulation with density and speed controls.
  - Interactive hover surges that pump rapid data packets through connected pipes.
- **Free Drag-and-Drop:** Drag any node anywhere; conduit pipes bend dynamically in real time and custom layouts persist in `localStorage`.
- **Zero Overflow Guarantee:** Strict SVG `clipPath` bounding ensures text never bleeds outside card boundaries.
- **Synthesized Cyber Audio:** Optional Web Audio API synthesizer generating harmonic blips and resonant whooshes.
